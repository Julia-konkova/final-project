# Итоговое задание

Данный проект является веб-сервером на Go, реализует функционал планировщика задач, который позволяет работать с задачами (добавлять, получать, изменять и удалять), также данный todo-list позволяет отмечать задачи выполненными. Задачи могут иметь срок исполнения и могут повторяться по заданным правилам.

Директория web содержит файлы фронтенда.
В директории tests находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Реализованы задачи со * по использованию переменных окружения TODO_PORT, TODO_DBFILE, они хранятся в файле .env
Для запуска приложения, необходимо склонировать репозиторий, используйте команду git clone https://github.com/Julia-konkova/go-final-project.git и запустить командой go run .
По адресу http://localhost:7540/ будет доступно приложение.
При запущенном приложении можно запусить все тесты командой go test ./tests.

Так же можно запустить приложение, используя Dockerfile, для этого используйте команду для создания образа: docker build -t juliakonkova/todo-list ., затем запустите контейнер командой: docker run -p 7540:7540 juliakonkova/todo-list, приложение также будет доступно по адресу http://localhost:7540/
